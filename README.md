> [!NOTE]
> **왜 DropKick인가요?**  
> 한국 영화·드라마 제작 환경에서 시나리오 양식이 통일되지 않아 겪는 비효율을 해결하기 위해 개발되었습니다.  
> 글로벌 표준(Fountain) 형식을 기반으로 **화면과 PDF 줄바꿈 100% 일치**, **3막 구조화(Save the Cat!)**, **인물 설정·통계 분석**, **안전한 수정고 관리**까지 단 하나의 프로젝트 패키지로 제공합니다.

---

## ✨ 주요 기능 (Key Features)

### 🎬 표준 시나리오 에디터 & 스마트 조판
- **6가지 표준 스타일 (`⌘1`~`⌘6`)**: 씬헤딩, 액션, 인물, 괄호지문, 대사, 전환
- **자동 씬 번호(S#) 매김**: 씬 순서가 바뀌어도 자동으로 번호 재정렬
- **스마트 자동 완성**: 이미 등장한 인물 이름을 감지하여 빠르고 오타 없이 입력

### 📄 화면 = PDF 100% 일치 (정밀 조판)
- **줄바꿈까지 일치**: 화면에서 보이는 페이지와 실제 출력되는 PDF의 페이지·줄바꿈이 완벽하게 일치
- **한글 맞춤 조판**: 단어 중간에서 끊기지 않는 자연스러운 줄바꿈 (Keep-all)
- **표준 표지 & 넘버링**: 원클릭으로 정식 규격 표지와 페이지 번호가 포함된 PDF 출력

### 🧩 3막 구조 스토리보드 (Save the Cat!)
- **15단계 핵심 비트 카드**: 1막(설정), 2막(대립), 3막(해결)에 맞춘 스토리 비트 카드
- **씬 드래그 앤 드롭 & 복제**: 원고 씬 서랍에서 마우스로 카드로 씬을 배치하고, `⌘` 키를 눌러 여러 카드에 복제
- **자유로운 구성 변경**: 단계 카드 추가/삭제, 순서 이동, 단계별 시놉시스 작성

### 🗂️ 올인원 프로젝트 파일 (`.dropkick`) & 프리셋
- **단일 패키지 관리**: Finder에서는 파일 하나로 보이며, 내부에는 스크립트·인물 설정·메모·수정고가 통합 보관
- **사이드바 트리**: 개요, 스크립트, 인물, 메모, 기타 폴더를 트리 구조로 자유롭게 관리
- **맞춤형 프리셋**: 기본 인물 양식과 3막 구조 외에도 나만의 커스텀 서식을 만들어 재사용

### 📊 실시간 통계 & 러닝타임 분석
- **분량 분석**: 전체 페이지 수 및 표준 기준(1페이지 ≈ 1분) 예상 러닝타임 실시간 계산
- **인물별 대사 점유율**: 등장인물별 대사 분량과 비중 시각화
- **씬별 호흡 분석**: 씬별 분량과 템포를 한눈에 파악하여 이야기 리듬 점검

### 🛡️ 안전한 자동 저장 & 수정고(Revisions) 관리
- **3초 자동 저장 & 스마트 백업**: 작업 중 손실 걱정 없는 실시간 저장 및 최대 100개 백업 보관
- **버전별 수정고 보관**: 1고, 2고, 3고 등 단계별 버전을 저장하고 언제든 비교 및 되돌리기

### 🌐 완벽한 표준 호환 (Fountain)
- 원고는 전 세계 업계 표준인 **Fountain** 오픈 텍스트 포맷으로 저장되어 Final Draft, Highland 등 타 시나리오 프로그램과 자유롭게 상호 호환

## 📥 다운로드 및 시스템 요구사항

<div align="center">

| 항목 | 사양 및 환경 |
|:---|:---|
| **지원 OS** | **macOS 13 (Ventura)** 이상 |
| **지원 아키텍처** | **Apple Silicon (M1 / M2 / M3 / M4)** 및 **Intel** 맥 (Universal 바이너리) |
| **보안 검증** | **Apple 공식 공증(Notarized)** 완료 |
| **최신 버전** | [**v0.2.1 바로 가기**](https://github.com/gotgam100/DropKick_releases/releases/latest) |

</div>

### 🚀 설치 방법
1. **[최신 버전 (.dmg) 받기](https://github.com/gotgam100/DropKick_releases/releases/latest)** 에서 `DropKick_버전_universal.dmg` 파일을 다운로드합니다.
2. 다운로드한 `.dmg`를 열고 **DropKick** 아이콘을 **응용 프로그램(Applications)** 폴더로 끌어 놓습니다.
3. 처음 열 때 "인터넷에서 다운로드한 앱입니다" 안내 창이 나타나면 **'열기'**를 클릭합니다.

> [!TIP]
> **애플 공식 공증 완료 안내**  
> DropKick은 Apple의 엄격한 보안 검사를 통과하여 공식 공증(Notarization)을 완료한 앱입니다. "확인되지 않은 개발자" 경고 없이 바로 안전하게 실행하실 수 있습니다.

## 🔄 스마트 자동 업데이트

- 새로운 버전이 출시되면 앱 실행 시 자동으로 감지하여 업데이트를 안내합니다.
- **'지금 설치'** 버튼 클릭 한 번으로 작업 중인 문서를 안전하게 저장하고 최신 버전으로 자동 갱신됩니다.
- *(메뉴의 **DropKick → 업데이트 확인…** 을 통해 수동으로 확인할 수도 있습니다.)*

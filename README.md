# DropKick

맥에서 쓰는 **한글 시나리오 작성 앱**입니다. 할리우드 형식으로 시나리오를 쓰고, 화면 그대로 PDF로 내보내고, 메모·인물 설정과 함께 한 프로젝트로 관리합니다.

## 다운로드

**[최신 버전 받기 →](https://github.com/gotgam100/DropKick_releases/releases/latest)**

`DropKick_버전_universal.dmg` 파일을 받으면 됩니다.

- macOS 13 (Ventura) 이상
- Apple Silicon(M1 이후)과 인텔 맥 모두 지원
- 애플 공증을 받은 앱이라 "확인되지 않은 개발자" 경고 없이 열립니다

## 설치

1. 받은 `.dmg`를 엽니다.
2. **DropKick**을 **응용 프로그램** 폴더로 끌어 놓습니다.
3. 처음 열 때 "인터넷에서 다운로드한 앱입니다" 창이 뜨면 **열기**를 누릅니다.

## 업데이트

새 버전이 나오면 DropKick을 켤 때 알려 줍니다. **지금 설치**를 누르면 알아서 받아 설치하고 다시 시작합니다. 메뉴 **DropKick → 업데이트 확인…** 으로 직접 확인할 수도 있습니다.

## 주요 기능

- 씬헤딩, 액션, 인물, 괄호지문, 대사, 전환 스타일 (`⌘1`~`⌘6`), 씬 번호 자동
- 화면과 똑같은 페이지로 PDF 내보내기, 표지
- 사이드바 프로젝트 트리: 개요, 스크립트(씬 목록), 인물 설정, 메모, 기타
- 통계: 페이지, 예상 러닝타임, 인물별 대사량, 씬 길이
- 인물 설정과 원고 연결, 인물 이름 일괄 바꾸기, 본문 찾기
- 자동 저장과 백업, 수정고(1고·2고 보관, 비교, 되돌리기)
- 원고는 표준 Fountain 형식이라 다른 시나리오 프로그램에서도 열립니다

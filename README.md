# DropKick(beta)

드롭킥(DropKick)은 맥OS 전용 **한글 시나리오 작성 프로그램**입니다.

한국 영화 제작 환경에서 시나리오 형식이 통일되지 않아 발생하는 불편함과 비효율성에 분개하여 개발되었습니다. 글로벌 스탠다드 형식을 기반으로 일관되고 전문적인 시나리오 작성을 지원합니다.
이 프로그램은 단순한 문서 작성을 넘어 체계적인 프로젝트 관리 환경을 제공합니다.

직관적인 폴더 형태의 사이드바를 통해 인물 설정과 메모 등 작품에 필요한 다양한 요소를 한곳에서 다룰 수 있으며, 여러 버전의 수정고 역시 하나의 프로젝트 내에서 통합하여 관리할 수 있습니다. 또한, 작성 중인 시나리오 및 프로젝트에 대한 통계와 분석 데이터를 제공하여 작가가 작품의 전체적인 흐름과 분량을 객관적이고 손쉽게 파악할 수 있도록 돕습니다.

## 다운로드

**[최신 버전 받기 →](https://github.com/gotgam100/DropKick_releases/releases/latest)**

`DropKick_버전_universal.dmg` 파일을 받으면 됩니다.

- macOS 13 (Ventura) 이상
- Apple Silicon(M1 이후)과 인텔 맥 모두 지원
- 애플 공증을 받은 앱이라 "확인되지 않은 개발자" 경고 없이 열립니다

## 설치

1. 받은 `.dmg`를 엽니다.
2. **DropKick**을 **응용 프로그램** 폴더로 끌어 놓습니다.
3. 처음 열 때 "인터넷에서 다운로드한 앱입니다" 창이 뜨면 **열기**를 누릅니다.

## 업데이트

새 버전이 나오면 DropKick을 켤 때 알려 줍니다. **지금 설치**를 누르면 알아서 받아 설치하고 다시 시작합니다. 메뉴 **DropKick → 업데이트 확인…** 으로 직접 확인할 수도 있습니다.

## 주요 기능

- 씬헤딩, 액션, 인물, 괄호지문, 대사, 전환 스타일 (`⌘1`~`⌘6`), 씬 번호 자동
- 화면과 똑같은 페이지로 PDF 내보내기, 표지
- 3막 구조 보드 (세이브 더 캣 15단계): 단계별 카드에 시놉시스를 작성하고, 원고 씬 서랍에서 드래그 앤 드롭으로 씬을 배치·복제하여 스토리 구조화
- 사이드바 프로젝트 트리 및 프리셋: 개요, 스크립트(씬 목록), 인물 설정, 메모 등 자유로운 문서 구성과 맞춤형 프리셋 지원
- 통계: 페이지, 예상 러닝타임, 인물별 대사량, 씬 길이
- 인물 설정과 원고 연결, 인물 이름 일괄 바꾸기, 본문 찾기
- 자동 저장과 백업, 수정고(1고·2고 보관, 비교, 되돌리기)
- 원고는 표준 Fountain 형식이라 다른 시나리오 프로그램에서도 열립니다
